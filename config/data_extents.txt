# (tools/data_owners.py: such an object is a "root", and without an entry
# here the NONMATCHING build keeps it and everything after it in its run
# where the data unit has it). One line per root: NAME EXTENT, the bytes
# from NAME the code can touch through the cast, or `self` for the object
# alone. Read off the code; the comment says where.
